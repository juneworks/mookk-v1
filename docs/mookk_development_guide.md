# 📚 Mookk 펀딩 플랫폼 쉽고 즐거운 개발 해설서 (중학생도 이해하는 버전!)

---

## 1. 💡 이 서비스는 한 마디로 무엇인가요?

**Mookk(묵)**은 **"책을 내고 싶은 작가(저자)"**와 **"그 책을 읽고 응원하고 싶은 독자(후원자)"**를 연결해 주는 **온라인 도서 크라우드펀딩 플랫폼**입니다.

텀블벅이나 와디즈 같은 사이트를 떠올리면 쉬워요! 작가가 책 아이디어와 목표 금액을 올리면, 독자들이 미리 예약을 하고 마감일에 목표 금액이 모이면 책이 실제 출판되어 배송되는 구조입니다.

---

## 2. 🧩 한눈에 보는 쉬운 개발 용어 사전

개발자들이 쓰는 어려운 단어들을 일상생활 속 비유로 쉽게 풀었습니다!

| 어려운 개발 용어 | 한 줄 비유 | 쉬운 설명 |
| :--- | :--- | :--- |
| **Next.js (넥스트 제이에스)** | 🏗️ 최신 건축 공법 | 웹사이트의 방, 문, 디자인, 기능을 깔끔하고 빠르게 만드는 최고급 웹 제작 틀(프레임워크)입니다. |
| **Supabase (수파베이스)** | 🏰 디지털 만능 서버 창고 | 회원 정보, 책 정보, 결제 내역 등을 안전하게 보관하고 필요할 때 꺼내주는 비밀 데이터 창고입니다. |
| **DB (Database, 데이터베이스)** | 📊 아주 큰 디지털 엑셀 장부 | 플랫폼의 모든 기록이 들어있는 데이터 정리함입니다. |
| **Schema (스키마)** | 📐 엑셀 표 설계도 | "이 표에는 이름, 이메일, 가입일을 넣자!"라고 정해놓은 표의 틀(양식)입니다. |
| **RLS (Row Level Security)** | 🔐 개인정보 보호 자물쇠 | "내 후원 정보는 나만 보고, 작가 정보는 해당 작가만 수정해!"처럼 데이터 접근을 막아주는 안전장치입니다. |
| **API (에이피아이)** | 👨‍🍳 서빙하는 식당 카운터 점원 | 손님(브라우저)이 "책 목록 보여줘!" 하고 요청하면 창고(DB)에 가서 음식을 가져다주는 전달자입니다. |
| **Mock Payment (가상 결제)** | 🎟️ 가짜 연습용 카드 결제 | 테스트할 때 실제로 돈이 나가면 안 되므로, 돈이 나간 것처럼 시뮬레이션해 보는 가짜 결제 시스템입니다. |
| **Billing Key (빌링키)** | 💳 "마감일에 결제할게요" 도장 | 카드번호를 직접 저장하면 위험하니까, 카드사에서 대신 발행해 준 **"나중에 결제 승인할 수 있는 디지털 결제 도장"**입니다. |
| **Batch Processing (배치 처리)** | 🏭 일괄 자동화 공장 기계 | 사람 100명이 결제 버튼을 누를 필요 없이, 마감일에 컴퓨터 기계가 100건을 한 번에 싹 처리하는 기술입니다. |
| **Settlement (정산)** | 🧾 최종 정산 영수증 | 모인 총 후원금에서 카드 수수료(3.3%)와 플랫폼 수수료(5.0%)를 떼고 작가님 통장에 들어갈 돈을 계산하는 일입니다. |

## 3. 🏁 Phase 0 ~ Phase 6 페이즈별 작업 내용 완전 해설

개발 현황판(`tasks.md`)에 나와 있는 6단계 작업을 순서대로 쉬운 이야기 형태로 알려드릴게요!

### 📌 Phase 0: 준비물 챙기기 (설계도와 작업판 세팅)
- **무슨 일을 했나요?**
  - 어떤 기능을 만들지 정리한 기획서(`prd.md`)를 정리하고, 21개의 할 일 체크리스트 현황판(`tasks.md`)을 만들었습니다.
- **비유하자면?**: 건물을 짓기 전에 건축 설계도를 그리고 작업 일기장을 준비한 것입니다.

---

### 📌 Phase 1: 서버 창고 만들기 & 집 짓기 (DB & 배포 파이프라인)
- **무슨 일을 했나요?**
  - Supabase(수파베이스)라는 데이터 창고를 만들고 5개의 핵심 엑셀 표를 설계했습니다:
    1. **User (유저 표)**: 회원들의 이름, 이메일, 역할(저자/후원자) 저장
    2. **Project (프로젝트 표)**: 책 제목, 목표 금액, 마감일, 책 소개글 저장
    3. **Reward (리워드 표)**: 독자가 받을 선물 세트(책+엽서, 싸인본 등) 가격 및 설명 저장
    4. **Pledge (후원 표)**: 누가 어떤 프로젝트에 얼마를 결제 예약하고 어디로 배송받을지 저장
    5. **Settlement (정산 표)**: 펀딩이 성공했을 때 작가님에게 줄 최종 금액 장부
  - 만들어진 웹사이트를 Vercel이라는 인터넷 서버에 올려서, 세상 어디서나 주소만 치면 들어올 수 있게 연결했습니다.

---

### 📌 Phase 2: 저자님과 독자님 문패 달아주기 (회원가입 및 역할 구분)
- **무슨 일을 했나요?**
  - 이메일과 비밀번호로 간편하게 가입하고 로그인/로그아웃할 수 있는 기능을 만들었습니다.
  - 가입할 때 **"저자로 시작하기"**와 **"후원자로 시작하기"** 중 선택하게 하여, 시스템이 각 사용자의 역할을 기억하도록 했습니다.
- **비유하자면?**: 놀이공원에 들어올 때 '작가 자유이용권'을 가졌는지 '독자 자유이용권'을 가졌는지 팔찌를 채워주는 것입니다.

---

### 📌 Phase 3: 책 프로젝트 올리기 (프로젝트 개설 & 화면 노출)
- **무슨 일을 했나요?**
  - 작가님이 직접 책 제목, 설명글, 목표 금액, 마감일, 책 표지 이미지를 올리는 화면을 구현했습니다.
  - 리워드(예: 15,000원 도서 1권 세트)를 여러 개 추가할 수 있게 만들었습니다.
  - 올린 프로젝트는 바로 메인 화면에 나오지 않고 **'초안(draft)'** 상태로 승인을 기다립니다.
- **비유하자면?**: 상점 주인(작가)이 매장에 올릴 신상품을 등록하고 창고에 잠시 대기시켜 둔 것입니다.

---

### 📌 Phase 4: 독자의 찜과 결제 예약 (가상 예약 결제)
- **무슨 일을 했나요?**
  - 독자가 마음에 드는 책 상세 페이지에서 리워드를 선택하고 이름, 전화번호, 배송지 주소를 입력합니다.
  - [가상 예약결제 완료] 버튼을 누르면 `mock_billing_key_xxxx`라는 가짜 결제 도장이 생성되며 "결제 예약 완료" 상태가 됩니다.
- **비유하자면?**: "이 책 마감일에 목표 금액 채워지면 그때 제 카드로 결제해 주세요!" 하고 **약속 도장**만 찍어두는 것입니다. (돈은 아직 안 나감!)

---

### 📌 Phase 5: 마감일 밤 12시! 자동으로 돈 계산하기 (마감 배치 결제 & 자동 정산)
- **무슨 일을 했나요?**
  - 펀딩 마감일이 되었을 때 자동으로 작동하는 백엔드 엔진(`app/api/batch-payment/route.ts`)을 개발했습니다.
  - **상황 A: 목표 금액 달성 실패 (예: 100만 원 목표에 50만 원 모임)**
    -> 프로젝트 상태가 `failed`로 변경되고, 모든 후원자들의 결제 예약이 자동으로 취소됩니다.
  - **상황 B: 목표 금액 달성 성공 (예: 100만 원 목표에 150만 원 모임)**
    -> 프로젝트 상태가 `succeeded`로 변경되고, 예약해 둔 카드로 일괄 결제가 승인(`paid`)됩니다.
    -> 모인 총액에서 **PG 카드 수수료 3.3%**와 **플랫폼 중개 수수료 5.0%**를 뺀 나머지 금액을 작가님 몫으로 연산하여 정산 장부(`Settlement`)에 저장합니다.

---

### 📌 Phase 6: 마이페이지 & 관리자 대시보드 (마이페이지 & 최종 QA)
- **무슨 일을 했나요?**
  - **독자 마이페이지**: 내가 과거에 후원한 내역과 배송 상태를 한눈에 볼 수 있습니다.
  - **작가 마이페이지**: 내가 등록한 책의 모금액과 마감 후 받게 될 예상 정산금을 확인할 수 있습니다.
  - **관리자 대시보드 (`/admin`)**: 
    1. 등록된 초안 프로젝트를 검토하고 **[수동 승인 (Live)]**을 눌러 메인 홈에 공개할 수 있습니다.
    2. 테스트를 위해 마감 배치를 강제로 돌려보고 정산 보고서를 즉시 출력할 수 있는 조종간을 만들었습니다.

---

## 4. 🌟 앞으로 무엇을 더 하면 완벽해지나요? (향후 로드맵)

1. **진짜 결제대행사(PG) 연결**: 현재는 연습용 가상 결제 도장을 쓰지만, 실제 오픈 시 아임포트(포트원)나 토스페이먼츠 연동 모듈로 교체합니다.
2. **시계 태엽 자동화 (Vercel Cron)**: 매일 밤 12시 마감된 프로젝트를 인간의 개입 없이 컴퓨터가 스스로 체크하여 배치를 돌리도록 시계 태엽을 감아둡니다.
3. **알림톡 / 이메일 발송**: 펀딩 성공 시 독자에게 "결제가 완료되었습니다", 작가에게 "정산이 완료되었습니다" 메시지를 발송합니다.
